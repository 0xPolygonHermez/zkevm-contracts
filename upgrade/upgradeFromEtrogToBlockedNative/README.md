# Upgrade From Etrog to Native Blocked

Script to create, schedule and execute transactions for upgrading bridge L2 from Etrog to the native-blocked sovereign version.

- `PolygonZkEVMBridgeV2Pessimistic` (Etrog) --> `AgglayerBridgeL2NativeBlockedFromEtrog`

This is a multi-step upgrade that:
1. Upgrades the bridge implementation
2. Calls `initializeFromEtrog` to set bridge manager, emergency roles, proxied tokens manager, and initialize the Local Balance Tree (LBT)
3. Blocks native gas token deposits and claims on L2 bridges where the gas token is not ether (`WETHToken != address(0)`)

Only the bridge is upgraded. The GER is not touched.

## Quick Start

1. **Create your environment file**

```bash
cp .env.example .env
```

Fill with `DEPLOYER_PRIVATE_KEY` or `MNEMONIC`, and set `CUSTOM_PROVIDER` to your L2 RPC URL.

2. **Copy and configure parameters**

```bash
cp ./upgrade/upgradeFromEtrogToBlockedNative/upgrade_parameters.json.example ./upgrade/upgradeFromEtrogToBlockedNative/upgrade_parameters.json
```

Fill in all addresses in `upgrade_parameters.json`. Leave `pathTokensJson` empty (tokens will be fetched automatically).

3. **Run the upgrade script**

```bash
./upgrade/upgradeFromEtrogToBlockedNative/upgrade_etrog_to_blocked_native.sh --old-tag v4.0.0-fork.7 --url https://your_l2_rpc
```

## Files

- `upgrade_etrog_to_blocked_native.sh`: Bash script that runs import manifest script + upgrade script
- `upgradeSovereignBridge.ts`: Main upgrade script that deploys implementations and creates timelock operations
- `upgrade_parameters.json`: Configuration parameters for the upgrade
- `upgrade_parameters.json.example`: Example configuration file
- `upgrade_output.json`: Generated output after running the upgrade script (created after execution)
- `test/shadowForkUpgrade.test.ts`: Shadow fork test validating all contract upgrades

Scripts in `tools/importOZInfoFromTag/`:

- `import_oz_info_from_tag.sh`: Bash script to get manifest for upgrade
- `force_import_old_contracts.ts`: Used inside import script

## Prerequisites

### Environment Setup

1. **Install packages**

```bash
npm i
```

2. **Set environment variables**

```bash
cp .env.example .env
```

Fill `.env` with your credentials:

- `DEPLOYER_PRIVATE_KEY` - Private key for deployment account
- `CUSTOM_PROVIDER` - L2 RPC URL for the upgrade (used by `--network custom`)

3. **Copy configuration files**

```bash
cp ./upgrade/upgradeFromEtrogToBlockedNative/upgrade_parameters.json.example ./upgrade/upgradeFromEtrogToBlockedNative/upgrade_parameters.json
```

4. **Tokens file (Optional)**
   You can optionally provide a `tokens.json` file containing the list of wrapped tokens and `initNativeSupply`. If not provided, the script will fetch this data directly from the bridge contract using `getLBTData`.

    If you want to use a pre-generated file, it must have the following structure (generated by `tools/getLBT/getLBT.ts` with `printTokens: true`):

```json
{
    "initNativeSupply": "200000000000000000000000000",
    "tokenAddresses": [
        "0xa2036f0538221a77A3937F1379699f44945018d0",
        "0x1E4a5963aBFD975d8c9021ce480b42188849D41d"
    ]
}
```

## Configuration

### Required Parameters

Update `upgrade_parameters.json` with the following values:

```json
{
    "unsafeMode": false,
    "bridgeL2Address": "0x..",
    "bridge_initParams": {
        "bridgeManager": "0x..",
        "proxiedTokensManagerAddress": "0x..",
        "emergencyBridgePauserAddress": "0x..",
        "emergencyBridgeUnpauserAddress": "0x.."
    },
    "pathTokensJson": "",
    "forkParams": {
        "rpc": "rpc url",
        "timelockAdminAddress": "0x.."
    }
}
```

### Parameters Description

#### Mandatory Parameters

- `bridgeL2Address`: Address of the bridge proxy on L2
- `bridge_initParams`:
    - `bridgeManager`: Address of the bridge manager role
    - `proxiedTokensManagerAddress`: Address of the proxied tokens manager role (must not be zero or bridge address)
    - `emergencyBridgePauserAddress`: Address that can pause the bridge in emergency
    - `emergencyBridgeUnpauserAddress`: Address that can unpause the bridge

#### Optional Parameters

- `pathTokensJson`: Path to `tokens.json` file with the list of wrapped tokens and `initNativeSupply`. If not provided, the script will fetch LBT data directly from the bridge contract and save `tokens.json` and `LBT.json` in this folder. (Example: `./upgrade/upgradeFromEtrogToBlockedNative/tokens.json`)
- `timelockSalt`: Unique salt for timelock operations (defaults to ethers.ZeroHash)
- `timelockDelay`: Timelock delay in seconds (defaults to minimum timelock delay)
- `maxFeePerGas`: Maximum fee per gas unit (optional, for EIP-1559 transactions)
- `maxPriorityFeePerGas`: Maximum priority fee per gas (optional, for EIP-1559 transactions)
- `multiplierGas`: Gas multiplier with 3 decimals (e.g., "1500" for 1.5x)
- `unsafeMode`: Boolean flag to disable critical tooling checks (default: false)

#### Fork Parameters (for testing)

- `forkParams.rpc`: RPC URL for shadow fork testing
- `forkParams.timelockAdminAddress`: timelock administrator address (proposer and executor address, to send transactions)

## Version Check

The upgrade script verifies the bridge contract has `BASE_INIT_BYTECODE_WRAPPED_TOKEN` (present in the Etrog bridge version). If not found, the script fails.

## Usage

### All in a single command

> Important: Run this command from the project's root directory.

Running the following command will:

```bash
./upgrade/upgradeFromEtrogToBlockedNative/upgrade_etrog_to_blocked_native.sh --old-tag v4.0.0-fork.7 --url https://your_l2_rpc
```

> `--old-tag` is the git tag of agglayer-contracts that was used to originally deploy the bridge (e.g. `v4.0.0-fork.7`). This is needed to recreate the OpenZeppelin manifest for the proxy.
> `--url` is the L2 RPC URL for the target network.

- Generate the required manifest using the provided tag to prepare the upgrade.
- Create the manifest inside the folder: `upgrade/upgradeEtrogSovereign/manifest-from-*` (shared with the EtrogSovereign upgrade tool).
- Copy that manifest automatically into the `.openzeppelin` folder in your project root.
- Execute the upgrade script, which will deploy the new implementation and output the timelock transactions needed for the upgrade.
- Afterwards, you can proceed to step 3 of the next section using that data.

### The steps separately

### 1. Prepare manifest

This command will generate the manifest in the `upgrade/upgradeEtrogSovereign/manifest-from-*` folder:

```bash
./tools/importOZInfoFromTag/import_oz_info_from_tag.sh --tag $TAG --url $RPC_URL
```

- `--tag`: Git tag of the agglayer-contracts repository that was used to originally deploy the bridge
- `--url`: L2 RPC URL for the target network

You'll need to copy this file into the `.openzeppelin` folder at your project root:

```bash
cp ./upgrade/upgradeEtrogSovereign/manifest-from-$TAG/* ./.openzeppelin/
```

### 2. Deploy Implementation

Once the manifest is correct, run the upgrade script to deploy the new implementation and generate timelock operations:

```bash
npx hardhat run ./upgrade/upgradeFromEtrogToBlockedNative/upgradeSovereignBridge.ts --network custom
```

> Note that the network must change depending on which network the upgrade is being performed on.

**Output files:**

- `upgrade_output.json`: All deployment addresses and transaction data
- `tokens.json`: Token addresses and initNativeSupply (generated if `pathTokensJson` not provided)
- `LBT.json`: Full LBT data (generated if `pathTokensJson` not provided)

### 4. Validate Upgrade (Fork Test)

Before executing on mainnet, validate using a shadow fork test.

Add `forkParams` to your `upgrade_parameters.json` (see configuration above), then run:

```bash
npx hardhat run ./upgrade/upgradeFromEtrogToBlockedNative/test/shadowForkUpgrade.test.ts
```

#### What the Fork Test Does

1. Forks the network at the block where the implementation was deployed
2. Verifies the timelock configuration and roles
3. Impersonates the timelock admin account
4. Captures storage values before upgrade
5. Sends schedule + execute transactions via timelock
6. Validates bridge version is `v1.3.0-blockGasToken`
7. Verifies all storage values are preserved
8. Verifies `initializeFromEtrog` parameters (bridge manager, emergency roles)
9. Verifies LBT initialization (all wrapped token balances)
10. Verifies native gas token bridging is blocked (on gas token networks)
